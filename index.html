Edición de video

Las herramientas que uso para editar.

Wondershare Filmora
EDICIÓN PRINCIPAL

Mi software principal de edición. Interfaz limpia, timeline intuitivo y efectos de calidad sin complicarse con software profesional pesado.

  • Edición multicapa con transiciones personalizadas
  • Efectos de color grading y LUTs
  • Keyframes para animaciones de texto y títulos
  • Audio ducking y mixer integrado
  • Screen recorder + editor en uno
Microsoft Clipchamp
EDICIÓN RÁPIDA / CLIPS

Para ediciones rápidas, clips de Twitch y contenido de formato corto. Directamente en el navegador, sin instalar nada.

  • Edición en browser — sin instalación
  • Clips de Twitch listos para TikTok/Shorts
  • Templates para contenido de formato corto
  • Integración nativa con OneDrive
  • Exportación directa a redes sociales

Python es el lenguaje base: scripts, automatizaciones, herramientas. RenPy lo extiende para crear visual novels con sistema de diálogos, ramas narrativas y manejo de sprites.

Desarrollo basado en eventos, sin escribir código tradicional. Muy usado para juegos 2D indie clásicos. Exporta a Windows, HTML5 y móvil.

El motor detrás de Undertale, Hotline Miami y Spelunky. GML es específico del engine pero muy eficiente para 2D — pixel art, roguelikes, metroidvanias.
